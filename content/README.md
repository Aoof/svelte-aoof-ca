# Website Content

This directory is the source of editable website content managed through Sveltia CMS.

- `settings.en.json` and `settings.fr.json` contain localized site settings.
- `home.en.json` and `home.fr.json` contain the localized home page copy.
- `skills.json` contains shared skill metadata and icon keys.
- `experience/`, `events/`, and `projects/` contain localized repeatable entries.

Content changes are committed to GitHub by Sveltia CMS and become visible after the normal site build and deployment.
